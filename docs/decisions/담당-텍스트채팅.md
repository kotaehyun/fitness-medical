# 결정: 담당 연결과 텍스트 채팅

협진·진단 시스템이 아니다. 회원 목록에 담당을 보이게 하고, 그 선으로만 텍스트 1:1을 연다.

## 결정

| 주제 | 결정 |
|------|------|
| 담당 | 회원 1명당 전문의 0~1, 트레이너 0~1 (`member_assignments`) |
| 목록 | 인증 전문가는 회원 전체를 보되, 이름 아래 작은 글씨로 담당 표시 |
| 채팅 | 담당 회원–전문의, 담당 회원–트레이너, 같은 회원을 같이 맡은 전문의–트레이너 |
| 매체 | 텍스트만. 이미지·영상·웹소켓 없음. 폴링 |
| 시드 | 김순자 ↔ doctor01·trainer01. 담당 변경 UI는 다음 |
| ADMIN | 메시지 없음 |
| 프론트 캐시 | 상대 목록 Query 키에 로그인 계정 id. 자기 자신과는 GET하지 않음 |

## 하지 않는 주장

실제 환자 배정, 임상 협진, 의사 대체, 상용 메신저가 아니다.
