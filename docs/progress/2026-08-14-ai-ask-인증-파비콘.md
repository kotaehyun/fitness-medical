# 2026-08-14 — `/api/ai/**` 로그인 필수 + 파비콘

## 결과

`POST /api/ai/ask`는 세션 없이 못 쓴다. `SecurityConfig`에서 `/api/ai/**`를 `authenticated()`로, **`/api/**` permitAll보다 앞**에 둠. 역할(MEMBER/PROFESSIONAL)은 나누지 않음. 로그인만.

브라우저 탭 아이콘: 로고와 같은 네이비 + 심박 SVG (`/favicon.svg`).

## 작업한 파일

- `SecurityConfig.java` — `[직접구현]` region에 `.requestMatchers("/api/ai/**").authenticated()`
- `AiController.java` — 주석만 (권한은 FilterChain)
- `SecurityAiAuthorizationTest.java` — 비로그인 401, MEMBER는 401 아님. `@Import(SecurityConfig.class)` 필요
- `backend/README.md` — `/api/ai/ask` 로그인 필수
- `frontend/public/favicon.svg`, `frontend/index.html`
- `PlaceholderPage` / `AppShell` — `workspaceLabel?` (checkJs)

## 설계 결정

- Controller에 `hasRole` 안 넣음. URL 매처가 입구.
- FastAPI `:8000`은 그대로. Spring 입구만 잠금.
- CSRF는 아직 `disable()` (로컬 시연). 이번에 안 함.

## 진행 중 겪은 문제와 해결

1. **테스트가 둘 다 403**  
   `@WebMvcTest`가 우리 `SecurityConfig`를 안 불러 기본 CSRF·미인증 403.  
   → `@Import(SecurityConfig.class)`. 미인증은 우리 entryPoint **401**.

2. **매처를 `/api/**` permitAll 뒤에 두면 무효**  
   첫 매칭만 쓴다. `/api/ai/ask`가 `/api/**`에 먹힘.  
   → members 다음, permitAll **앞**.
