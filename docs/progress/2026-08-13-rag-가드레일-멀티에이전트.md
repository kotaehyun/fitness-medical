**흐름:** 질문 → Router(의도) → Retriever(Chroma, 먼 Chunk 버림) → Writer(LLM) → Guard → 답변.

AI 꺼짐/타임아웃 → Spring **503** + 한국어 안내.

## 설계 결정

- 프론트는 FastAPI `:8000`을 직접 안 부름. 세션·CORS는 Spring.
- 역할 파이프라인 = 멀티 에이전트 **입구**. LangChain이라고 안 함.
- `/api/ai/**`는 08-14부터 로그인 필수. CSRF는 아직 disable.

## 진행 중 겪은 문제와 해결

1. **관련 없는 Chunk가 답에 섞임**  
   top-k만 쓰면 유사도 낮은 문단이 Writer로 감.  
   → `MAX_DISTANCE=0.55`, 넘으면 버림.

2. **프론트에서 FastAPI 직접 호출**  
   CORS·세션과 충돌.  
   → `POST /api/ai/ask`만.

3. **AI 꺼진 채 질문 → 프론트 500/네트워크 에러**  
   → Spring이 FastAPI 실패를 **503** + 안내로 변환.

4. **가드레일 없이 단정적인 건강 문구**  
   → Guard에서 진단·처방처럼 단정하지 않게. 생활 안내만.

5. **Vite 한글 경로 ENOENT (`개발` NFC/NFD)**  
   → 터미널 `cd` 실제 경로.

6. **checkJs: `catch (requestError)` unknown**  
   → `instanceof Error` 후에 `.message`.
