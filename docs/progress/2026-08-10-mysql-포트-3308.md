# 2026-08-10 — MySQL 호스트 포트 환경별 안내 (STUDY_TASKS 5단계)

## 결과

Docker MySQL 호스트 포트가 기기마다 다름. RTX 4090 노트북은 **3308**(3307은 로컬 mysqld가 사용), Mac 등은 3307. README에 환경변수 예시를 적어 5단계 학습 시 연결 실패를 줄임.

로컬 기본 학습은 여전히 **H2 `local`**. MySQL은 `mysql` 프로필. Flyway는 아직 없음.

## 작업한 파일

- `backend/README.md` — `DB_URL` 포트, `SPRING_PROFILES_ACTIVE=mysql`
- `docker/README.md` — 호스트 포트 안내

## 진행 중 겪은 문제와 해결

1. **`mysql` 프로필로 기동했는데 Connection refused / Access denied**  
   컨테이너는 떠 있는데 호스트 포트가 문서의 3307과 다름. 이 PC에 이미 mysqld가 3307을 씀.  
   → Docker 매핑을 **3308**, URL도 `jdbc:mysql://localhost:3308/fitness_medical?...`

2. **H2로 테스트한 데이터가 MySQL에 없음**  
   `local`은 메모리 H2 `create-drop`. 프로필을 바꾸면 DB가 완전히 다름.  
   → 시드는 `DemoDataConfig` `@Profile("local")`만. MySQL에는 자동 삽입 안 함.

3. **8080 vs 3306/3307/3308을 섞어 착각**  
   앱 포트(8081)와 DB 포트는 별개. Oracle XDB 8080 문제와 무관.  
   → 앱 `SERVER_PORT=8081`, DB는 `DB_URL` 호스트 포트.

## 실행 예시 (RTX 노트북)

```bash
SPRING_PROFILES_ACTIVE=mysql \
DB_URL='jdbc:mysql://localhost:3308/fitness_medical?serverTimezone=Asia/Seoul&characterEncoding=UTF-8' \
DB_USERNAME=fitness_user \
DB_PASSWORD=fitness_dev_2026 \
SERVER_PORT=8081 \
./gradlew bootRun
```
