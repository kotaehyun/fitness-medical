# 2026-08-16 — 담당 표시와 텍스트 대화창

## 결과

회원 목록에 담당 전문의·트레이너를 작은 글씨로 표시한다. 그 연결로만 텍스트 1:1을 연다. 말풍선에 보낸 시각을 표시한다. 이미지·웹소켓·협진 기록은 없다.

- `docs/decisions/담당-텍스트채팅.md`

## 설계 결정

- 목록은 전체, 채팅은 담당만
- 시드 담당만. 관리자 배정 UI는 다음
- 상대 목록 Query 키에 계정 id를 넣는다. 로그인 바꿔도 이전 상대를 그대로 부르지 않는다

## 진행 중 겪은 문제

1. **GET `/api/messages?peerAccountId=3` 이 400**  
   `doctor01` id가 3이고, 회원 화면에서 고른 전문의도 3이다. 전문의로 다시 로그인한 뒤 `['messages','peers']` 캐시가 그대로라 자기 자신과 대화를 요청함.  
   → Query 키에 `account.id`, 목록에 없는 상대·자기 자신은 요청하지 않음. 서버 메시지는 「나와의 대화는 보낼 수 없습니다.」
2. **checkJs `mutate(body)` — string을 void에 못 넣음**  
   `useMutation`이 인자를 void로 추론. `/** @type {string} */ body`로 표시.
