# Fitness Medical 담당 연결·텍스트 채팅 보고서

## 작업 일자

2026-08-16

## 작업 목적

전문가–회원을 한 덩어리로 두지 않고, **전문의–회원 / 트레이너–회원 / 같은 회원을 맡은 전문의–트레이너** 선만 텍스트로 대화하게 한다. 협진·진단·파일 첨부는 넣지 않는다.

## 배경

인증된 PROFESSIONAL은 회원 목록 전체를 본다. 채팅까지 전원에게 열면 담당 설명이 깨진다. 목록의 작은 「담당」글씨와 대화 상대를 같은 `member_assignments`에 둔다.

## 주요 작업

- 테이블: `member_assignments`, `chat_messages`
- API: `GET /api/messages/peers`, `GET/POST /api/messages` (로그인 필수, `/api/**` permitAll보다 앞)
- 화면: 회원·전문가 사이드바 메시지, 말풍선 시각
- 시드: 김순자 ↔ doctor01·trainer01 (기존 파일 H2도 보정)
- 테스트: 담당 아닌 전문가 403, 담당 전문의 전송 성공

## 문제와 해결

1. 회원으로 보다가 전문의로 로그인하면 상대 id 3(자기 자신)을 그대로 GET → 400. Query 키에 계정 id, 자기 자신은 요청하지 않음.
2. checkJs `mutate(string)` vs void. `body`에 `@type {string}`.

## 하지 않는 것

담당 변경 UI, 이미지·영상, 웹소켓, 임상 협진.
