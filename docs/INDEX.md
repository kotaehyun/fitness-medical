# docs

Fitness Medical 프로젝트의 학습/진행 기록용 문서 폴더입니다. `README.md`, `backend/README.md`, `backend/STUDY_TASKS.md`, `backend/erd/` 같은 기존 안내 문서와는 별도로, **작업하면서 남기는 기록**을 카테고리별로 모아둡니다.

## 카테고리

- [`progress/`](./progress) — 세션별/날짜별 진행 상황 로그. "오늘 뭘 했고 뭐가 남았는지" 기록.
- [`decisions/`](./decisions) — 설계 결정 기록. STUDY_TASKS의 "직접 결정" 항목처럼 정답이 하나가 아닌 선택을 왜 그렇게 했는지 남김.
- [`troubleshooting/`](./troubleshooting) — 삽질하고 해결한 문제 기록. 같은 문제를 나중에 또 만났을 때 바로 찾아보기 위함.

## 작성 규칙

- 파일명은 `YYYY-MM-DD-주제.md` 형식을 기본으로 합니다 (진행 상황/트러블슈팅). 설계 결정은 주제 이름만으로 충분합니다.
- 새 문서를 추가할 때 이 파일의 카테고리 목록에 링크를 추가합니다.
